# Power BI Sales Dashboard

This project demonstrates an interactive Power BI dashboard designed for small and mid-sized businesses.

## Dashboard Insights
- Total Sales and Quantity KPIs
- Sales trend over time
- Top-performing products
- Region-wise sales analysis
- Interactive slicers for filtering

## Tools Used
- Power BI Desktop
- Excel (Sample Sales Data)

This dashboard focuses on clarity, usability, and actionable insights.
